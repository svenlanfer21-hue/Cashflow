# Cashflow – NON PLUS ULTRA

Kostenlose, offlinefähige Budget-PWA. Keine persönlichen Finanzdaten im Repository.

## Installation
Alle Dateien in das Stammverzeichnis des GitHub-Repositories hochladen. Unter Settings → Pages → Deploy from a branch → main / (root) auswählen. Danach die GitHub-Pages-URL in Chrome öffnen und über das Browsermenü installieren.

## Hinweise
- Lokale Daten im Browser (localStorage), keine Cloud-Synchronisation.
- Manuelle JSON-Backups sind **nicht verschlüsselt**. Sicher aufbewahren.
- Bei Kontostandsaktualisierung keine bereits gebuchten Ausgaben als offen doppelt berücksichtigen.
- Lebensmittel-Wochenbudget ist ein Richtwert, keine automatisch abgezogene Monatsausgabe.
- Fixkostenstatus wird monatsweise gespeichert; wiederkehrende Zahlungen werden monatlich erneut als offen angezeigt.
